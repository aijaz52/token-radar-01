A snapshot-based radar for pre-token protocols, ranked by implied value using TVL, growth, maturity, category, and chain breadth. The dark radar console includes sortable rankings, search and category filters, inspectable model components, and complete farm plans. Runs with Node 22 and no dependencies; open `out/dashboard/index.html` after generating the output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
